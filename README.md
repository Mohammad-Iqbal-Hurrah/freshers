# Freshers' Party 2026 — Invitation Website

A responsive, static Vercel-ready website for the Data Science × AIML Freshers' Party.

## Files
- `index.html` — main page
- `styles.css` — responsive styling
- `script.js` — video controls, reveal animations, Add to Calendar
- `assets/invitation.png` — final invitation artwork
- `assets/invitation.mp4` — animated invitation

## Run locally
Just open `index.html` in a browser, or use VS Code Live Server.

## Deploy to Vercel
Upload this folder to a GitHub repository and import the repository in Vercel.
No build command is required because this is a static HTML/CSS/JS site.

If Vercel asks:
- Framework Preset: Other
- Build Command: leave empty
- Output Directory: `.`

## Note
The site uses Google Fonts via CDN. Everything else is local.
